==================================

2. Choose Add file > Upload files.
3. Upload ALL CONTENTS of this Step 2 folder to the repository root.
4. Existing files index.html, css/, js/, data/ should be replaced by this Step 2 version.
5. Upload assets/ with the real dashboard screenshots.
