01

Upload to MOZA CM2

  1. Download the Bugzila dashboard file prepared for CM2.
  2. Open MOZA Pit House on your PC and connect the CM2.
  3. Go to the dashboard / display import screen for the connected CM2.
  4. Import the Bugzila .mzdash file, then apply or sync it to the device.
  5. Select the imported dashboard on the CM2 and confirm the page loads correctly.

Pit House menu names may vary slightly by version, but the workflow remains: connect device → import dashboard → apply to device.

02

Upload to MOZA KS Pro

  1. Download the Bugzila dashboard file prepared for KS Pro.
  2. Open MOZA Pit House and connect the KS Pro wheel.
  3. Open the wheel display / dashboard import area for KS Pro.
  4. Import the correct .mzdash file and sync it to the wheel.
  5. Select the uploaded dashboard on the KS Pro display before entering the sim.

Always use the dashboard file that matches the target hardware family.

03

Switch KS Pro Pages 2 / 3

For the current Bugzila KS Pro multi-page layouts, hold the top-left button near TC, then use the 7-way joystick left / right to change between dashboard pages.

If more than one dashboard set is installed, use the 7-way joystick up / down while holding the same button to switch between dashboard sets.

This guidance reflects the current Bugzila KS Pro setup. If you remap controls in MOZA Pit House, the exact button behavior may differ.
